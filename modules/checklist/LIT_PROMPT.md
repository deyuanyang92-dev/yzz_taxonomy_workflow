# 文献抽取任务: 沙蚕科物种 × 采集地 (固定子代理提示词)

禁止调用 Agent 工具 (不得再开子代理)。只用 Read / Write / Bash 读写文件; 不联网。

输入: `.../checklist/lit_inbox/todo_<ID>.md` —— 一篇文献 (或文选中的若干页) 的 OCR 文本, 每页以 `=== p0012 ===` 开头 (PDF 页号)。
文件头给出: pid、PDF 路径、配置中的参考文献 (可能不全)、页码范围。
输出: 同目录 `done_<ID>.tsv` (UTF-8, Tab 分隔, 首行表头, 列顺序固定):

```
物种名（中文）	物种名（学名）	采集地	参考文献	页码	采集地类型	note	原文摘录	把握度
```

## 抽什么
- **只抽分类学文献的记录** (用户 2026-10-10: "我们是分类学文献名录整理, 不是生态调查")。
  收: 物种分类记述 (形态描述/新种/新记录/重描述/修订)、附标本的分类名录。
  不收: 生态调查 (群落、数量、生物量、站位分布统计)、动物地理/区系分析、养殖/生理/分子等文章 —— 即使它们列出了物种和地点。
  文选/集刊里混有这类文章时, 跳过整篇; 整块都不是分类文献 → 只写表头。
- **只抽沙蚕科 (Nereididae) 物种**, 含溪沙蚕亚科 (Namalycastis, Namanereis, Lycastis…)。其他科一律不要。拿不准是否沙蚕科 → 照抽, note 写"科未确证"。
- 每个 "物种 × 采集地类型 × 文献" 一行。同一种在同一文献中多处出现 → 合并为一行, 采集地用 `；` 连接, 页码用 `,` 连接。
- **采集地类型** 只能是:
  - `研究标本` —— 作者检视的标本/采样站位 ("标本采集地""材料""Material examined"、分类名录中随种列出的标本产地)
  - `模式产地` —— 本文新种/新亚种的正模/模式产地 (同时再写一行 `研究标本` 列全部标本产地)
- **不抽"地理分布""分布""Distribution"段** (用户 2026-10-11: "我要求是采集地信息, 没有让整理分布地信息")。
  某种在该文献中只有分布段、没有标本采集地 → 写一行 `研究标本`, 采集地留空, note 只放讨论 (若有)。

## 各列规则 (用户 2026-10-10 确认)
- **物种名（中文）**: 原文中文名; 原文没有则留空, 不自造, 不从别处补。
- **物种名（学名）**: 原文学名 + 命名人, 年份, 照录 (OCR 粘连的空格要补回, 如 `Perinereisnuntia` → `Perinereis nuntia`; 明显 OCR 错字可改并在 note 记 "OCR 校正: 原作 xxx")。新种按原文写 (如 `Nereis xxx sp. nov.` 写成 `Nereis xxx 作者, 年份`, note 写 "新种")。
- **采集地** (用户 2026-10-12 纠正: "取第一个。"是我自己的简化, 不是用户的规则; 用户原话 = "标本采集地是采集地, 但里面混有一些说明, 说明放 note"): 
  "标本采集地/材料"段里**所有采集点信息**——地点、水深、底质、采集日期/季节、标本数、采集者/船名、正模副模的产地——原文照录, **可以跨多句**
  (有的书每个采集点各写一句、每句以"。"结尾, 这些全部算采集地, 句间用"；"连接)。
  **按内容判断, 不按句号切**: 生境/栖息习性、同栖动物、盐度/温度、行为、生殖状态、保存地点等**说明**不进采集地。
  遇到特殊写法 (地点嵌在说明句里、一句里既有采集点又有说明等) 由你判断; 拿不准时把整句放采集地并在 note 的 [注: …] 里说明。
  区系/生态表格中: 列出该种出现的地点/站位名。
- **note** (用户 2026-10-11 示例: 动物志 (3) 羽须鳃沙蚕): 依次为
  1) "标本采集地"段中**不属于采集点信息**的文字 (生境、同栖动物、盐度等说明), 照原文;
  2) 若该种有"讨论"段: 接 `；讨论：` + 讨论段全文 (照原文)。
  **不要**放形态描述 (体长、刚节数、疣足等)、地理分布、异沙蚕体描述。
  你的提示 (新种、OCR 校正、科未确证、跨页等) 放在最后, 用 `[注: …]` 括起来。
- **参考文献**: 本篇原始文献的完整引文 (作者, 年份, 题名, 刊名, 卷(期): 页码), 以文献首页/页眉/"原载"注为准; 文选中的文章写原始出处并加 `[收录于 吴宝铃文选(上/下册), 1999]`; 实在找不到写配置中的参考文献。
- **页码**: 原书/原刊印刷页码; 看不到印刷页码就写 PDF 页号并加前缀 `pdf`, 如 `pdf12`。
- **原文摘录**: 支撑这一行的原文片段 (≤80 字), 便于核对。
- **把握度**: `高` (原文清楚) / `中` (OCR 有缺字但可推断) / `低` (OCR 严重损坏、无法确认)。

## 硬规则
1. **只依据给定文本**, 缺失留空, 不猜, 不用自己的知识补地名或学名。
2. OCR 文本难以辨认而又关键 (学名、地名) 时, 可用 `pdftoppm -r 200 -f <页> -l <页> -png "<PDF>" /tmp/x` 渲染该页后 Read 图片核对; 每个 todo 最多看 10 页图。
3. 本块没有任何沙蚕科记录 → 只写表头行, 照常输出 done 文件。
4. 每抽完约 20 行就把当前结果写入 `done_<ID>.tsv` (覆盖), 中途中断不丢进度。
5. 最终回报只一行: `done_<ID>.tsv: N 行, 低把握度 M 行`。不要贴表格内容。
