# checklist 模块 — 需求与状态

## R1 从专著/文献抽取「物种名录 + 采集地」表（2026-10-10 提出，状态：2026-10-11 首版完成）

**用户原话**：从专著或文献中获取沙蚕科物种名录、采集地信息，方便后续研究。

### 输出表（用户已定的 4 列，顺序固定）
| 列 | 内容 | 规则 |
|---|---|---|
| 1 物种名（中文） | 文献原文中文名 | 原文无中文名 → 留空，不自造 |
| 2 物种名（学名） | 拉丁名 + 命名人, 年份 | 按文献原文；斜体在 Excel 中保持 |
| 3 采集地 | 该文献记录的采集/分布地点 | 优先"研究标本/材料"段，其次"地理分布"段；多地点用 `; ` 分隔，原文照录 |
| 4 参考文献 | 作者, 年份, 书/刊名, 页码 | 每行可追溯到具体页 |

注意：此表按用户要求含中文列，属于对 CLAUDE.md"分类学内容一律英文"的用户特许例外。

### 附加列（2026-10-10 用户确认）
| 列 | 内容 |
|---|---|
| 5 页码 | 原书页码（抽查用） |
| 6 采集地类型 | 研究标本 / 文献记载分布 / 模式产地 |
| 7+ 现行有效名 | 用 `python3 yzz.py match` 批量匹配 WoRMS（见 R2），追加 AphiaID / status / valid_name / name_changed / check_note |

| note | "标本采集地"段中第一个"。"之后的说明（同栖动物、生境等），到"形态特征"前为止 |

用户示例（CN01《中国动物志》第33卷 (24)）：
- 中文名 `突齿沙蚕`；学名 `Leonnates indicus Kinberg, 1866`
- 采集地 = `广东大亚湾，海南陵水、新村，南海北部湾（水深 29 m）`（"标本采集地"后到第一个"。"）
- note = `在海南新村的黎安，同栖的动物有海绵、石珊瑚和红角沙蚕 Ceratonereis erythraeensis Fauvel 等。`

OCR：tesseract chi_sim 中文严重乱码，不可用；改用 RapidOCR（`11_mono_ocr.py`），其拉丁名会丢空格，学名需用 tesseract 文本/WoRMS 匹配校正。

- **不要**采集地英文标准化 + 经纬度（用户：后续再说）。

### 数据来源（首批）
- 已 OCR 的知识库：`/mnt/n/沙蚕科-知识库/kb.db`（表 `papers`, `pages`；OCR 已完成）
  - CN04 吴宝铃, 孙瑞平, 杨德渐 1981《中国近海沙蚕科研究》235 页
  - CN05 杨德渐, 孙瑞平 1988《中国近海多毛环节动物》359 页
  - CN01 孙瑞平, 杨德渐 2004《中国动物志 无脊椎动物 第三十三卷 沙蚕目》
- 原 PDF 均为扫描版（无文字层），只能用 OCR 文本 + 原图核对。

### 模型分工
- OCR 文本切分、按种定位页码：脚本 / haiku
- 逐种抽取 4 列（读 OCR 文本，按模板输出）：sonnet
- 难点（OCR 错字导致学名/地名不确定、异名判断、表格跨页）：主线程最高模型，必要时回看原 PDF 页图
- 最终抽查：主线程随机核对 ≥10% 行与原页

### 验收
- 每行可追溯到 (pid, 页码)；缺失留空不猜
- 回归测试：抽 CN01 中若干已知种，核对中文名、学名、采集地与原页一致
- 输出 Excel 交付前跑 `python3 yzz.py zh check`

## R2 WoRMS 批量名称匹配（2026-10-10，状态：已实现）

- 代码：`lib/worms_match.py`；测试：`tests/test_worms_match.py`（离线）

- 知识库交付件 `/mnt/n/沙蚕科-知识库/名录/Nereididae_物种名录.xlsx`：**一个表、每个物种×每篇文献一行**。
  列：物种名（中文）| 物种名（学名）| 采集地 | 参考文献 | 页码 | 现行有效名 | note。
- 采集地 = "标本采集地"段中所有采集点信息（可跨多句；新种另注"模式产地：…"）。**不收地理分布**。（2026-10-12 修正：原写"到第一个。"是我的简化，见 R6）
- note = "标本采集地"段中非采集点的说明（生境、同栖、盐度等）+ "；讨论：" + 讨论段全文。不放形态描述。
  用户示例：动物志 (3) 羽须鳃沙蚕 → 采集地"海南三亚"；note"穴居于底泥中……19.52‰。；讨论：赫列勃维奇（1963）……"。
- 只有分布段、无标本采集地的种：保留一行，采集地留空。
- 非沙蚕科表、文选重复表、WoRMS 明细等只留在工作流 04_处理数据，不进知识库文件。

## R5 经验规则库（借鉴 OASIS SEEL，2026-10-11）
参考：Han Y, …, Qian Q, Shang L. 2026. OASIS, a self-evolving AI scientist that integrates omics data and literature
knowledge for plant stress research. Molecular Plant. doi:10.1016/j.molp.2026.09.005（笔记：/mnt/n/沙蚕科-知识库/文献笔记/OASIS_2026_方法笔记.md）。
- OASIS 不训练/不微调模型（原文 l.412："without updating model weights"）；靠多智能体分工、证据可追溯、Reviewer、SEEL 规则沉淀。
- SEEL 规则 5 字段：任务类型、触发条件、失败特征、纠正动作、预期结果；附来源轨迹、版本、日期、验证状态；可回滚（原文 l.684-690）。
- 本模块对应实现：`RULES.tsv`（同 5 字段 + 来源=用户原话 + 版本 + 验证=回归测试 + 状态）。
  用户每次纠正 → 先加一条规则 + 一条回归测试 → 再改代码/提示词。规则停用改"状态"，不删除（可回滚）。

## R6 采集地/note 按内容判断，不按句号切（2026-10-12 用户纠正）
用户："采集地取第一个是你为了优化的规矩，我只是让你提取，有些信息确实会出现你说的问题，应该可能要兼容一些规则？遇到特殊就你自己模型判断？"
- 用户的规则是语义的："标本采集地是采集地，但里面混有一些说明，说明放 note"。"到第一个。" 是我从突齿沙蚕示例推广出的简化，已废止（RULES.tsv R01 停用，R11 取代）。
- 做法：采集点信息（地点/水深/底质/日期/标本数，可跨多句）→ 采集地；说明 → note；特殊情况由模型按内容判断。
- 实现：`17_resplit_prep.py` 把所有采集地行（含 note）交 sonnet 逐行重分 → resplit/done_*.tsv；15 `apply_resplit` 应用，
  **校验：新旧(采集地+note)去标点后字符多重集相同(不增不减)**，不通过则保留原值并报告。
