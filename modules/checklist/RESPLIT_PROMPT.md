# 采集地 / note 重分任务 (固定子代理提示词)

禁止调用 Agent 工具 (不得再开子代理)。只用 Read / Write / Bash; 不联网; **不需要看 PDF**, 只重新分配已有文字。

输入: `.../checklist/resplit/todo_<K>.tsv`, 列: rid, 物种名（学名）, 物种名（中文）, 采集地类型, 采集地, note。
输出: 同目录 `done_<K>.tsv` (UTF-8, Tab 分隔, 首行表头, 每个输入行恰好一行): `rid	采集地	note	依据`

## 用户的规则 (2026-10-12 原话)
"标本采集地是采集地, 但里面混有一些说明, 说明放 note。" "遇到特殊就你自己模型判断。"
- **采集地** = 所有**采集点信息**: 地点、水深、底质、采集日期/季节、标本数、采集者/船名、正模副模的产地 (可跨多句; 句间用"；"连接)。
- **note** = **说明**: 生境/栖息习性、同栖动物、盐度/温度、行为、生殖状态、标本保存地点等; 以及 "；讨论：…" 段和末尾的 `[注: …]`。
- 不按句号机械切分。有的书每个采集点各写一句 (如 "海南岛三亚…（25标本）。" "福建霞浦…（2标本）。"), 这些都归采集地。
- 现在的"采集地"可能只取了第一句, 后面仍在列采集点的句子在 note 里 → 移回采集地; 也可能"采集地"里混进了说明 → 移到 note。
- 拿不准的特殊写法 (地点嵌在说明句里、一句兼有采集点和说明等): 你自己判断; 整句放哪边都行, 在"依据"里写一句理由。

## 硬规则 (有脚本校验, 不通过会被拒绝)
1. **只重新分配, 不增不减不改字**: 新采集地 + 新 note 去掉标点和空白后的字符, 必须与旧采集地 + 旧 note 完全一致 (只允许移动句子, 和增删句间的 "；。，" 标点)。**不要**改错字、不要补字、不要翻译、不要删 [注: …]。
2. "；讨论：…" 和 `[注: …]` 原样留在 note 末尾, 不动。
3. 原本分得对的行 → 原样输出, 依据写 "不变"。
4. "依据" 一句话 (≤40 字), 写移动了什么或为什么不变。
5. 每完成约 20 行写一次文件。用 Python csv 模块写。
6. 最终回报一行: `done_<K>.tsv: 共 N 行, 改动 M 行`。
