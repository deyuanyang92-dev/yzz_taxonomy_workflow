# 标黄行复核任务 (固定子代理提示词)

禁止调用 Agent 工具 (不得再开子代理)。只用 Read / Write / Bash; 不联网。

输入: `.../checklist/review/todo_<K>.tsv` —— 名录中被标黄 (需核对) 的行。列: rid, 中文名, 学名, 采集地, 采集地类型, 页码, note,
parse_flag (抽取时的疑点), check_note (WoRMS 匹配疑点), valid_name, pid, PDF (原书路径), PDF页 (估计的 PDF 页号, 可能是范围)。
输出: 同目录 `done_<K>.tsv` (UTF-8, Tab 分隔, 首行表头, 每个输入行恰好一行):

```
rid	结论	字段	新值	依据
```

- **结论** 只能是: `确认` (原值与原书一致) / `修改` (原值有误, 给出正确值) / `删除` (不是该文献的沙蚕科分类记录, 如生态描述、检索表、目录、重复抽取)。
- **字段** (仅 修改 时填): `物种名（中文）` / `物种名（学名）` / `采集地` / `采集地类型` / `页码` / `note` 之一; 一行要改多个字段 → 写多行, rid 相同。
- **新值**: 照原书原文 (含命名人、年份; 地名照录)。
- **依据**: 简述你在原书哪一页看到了什么 (≤60 字), 如 "pdf106 地理分布: 南海我国中沙群岛"。

## 做法
1. 用 `pdftoppm -r 150 -f <页> -l <页> -png "<PDF>" /tmp/rv_<K>` 渲染 PDF页, Read 图片核对。PDF页 是范围时先看 OCR 文本
   (`.../checklist/ocr/<pid>/p<4位页号>.txt`) 定位到具体页再渲染。每块最多看 30 页图。
2. 判断依据只来自原书页面; 不用自己的分类学知识改学名或地名。原书本身印错 → 结论 `确认`, 依据写 "原书如此"。
3. WoRMS 问题 (check_note: 无匹配/非精确/粘连等) 通常是学名 OCR 错: 核对原书拼写, 若 OCR 错就 `修改` 物种名（学名）为原书拼写; 原书拼写本就与 WoRMS 不同 → `确认`, 依据写原书拼写。
4. 每完成约 10 行就写入 `done_<K>.tsv` (覆盖)。用 Python csv 模块写。
5. 最终回报一行: `done_<K>.tsv: 确认 a, 修改 b, 删除 c`。

## 采集地 / note 的划分 (2026-10-12 用户纠正)
采集地 = "标本采集地/材料"段中所有采集点信息 (地点、水深、底质、日期、标本数, 可跨多句); 生境、同栖、盐度等说明进 note。
**不要**机械地"取到第一个句号"; 按内容判断。核对时发现后面的句子仍在列采集点 → `修改` 采集地 (并把 note 里对应部分去掉)。
